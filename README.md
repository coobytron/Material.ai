# Material.ai

Material.ai is a dual-agent decision lab built around two complementary reasoning systems:

- **Ari — White Knight:** strategic synthesis, planning, and pattern recognition.
- **Mike — Black Knight:** adversarial review, counterarguments, and premise testing.

The interface stages both agents on a monochrome chessboard and turns any prompt into a structured debate, rebuttal, and final synthesis.

## Operating modes

- **Demo mode:** deterministic, local, dependency-free simulation that works on GitHub Pages.
- **Claude mode:** server-side Anthropic Messages API integration using separate Ari and Mike system prompts. The API key remains on the server.
